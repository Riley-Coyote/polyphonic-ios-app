## 🧠 AGENT ORCHESTRATION STRATEGY

### Parallel Processing Architecture

When working on Polyphonic, ALWAYS consider using multiple specialized agents in parallel:

#### Core Development Agents

1. **Code Implementation Agent**
   - Primary: Write actual implementation code
   - Focus: TypeScript, React Native, API integrations
   - Never wastes time on research when implementing known patterns

2. **Architecture Review Agent**
   - Continuous: Review code for patterns, performance, security
   - Focus: Best practices, optimization opportunities
   - Runs in parallel with implementation

3. **Testing Agent**
   - Continuous: Write tests as code is implemented
   - Focus: Unit tests, integration tests, edge cases
   - Never let untested code accumulate

4. **Documentation Agent**
   - Continuous: Update blueprint and inline docs
   - Focus: Keep POLYPHONIC_PROJECT_BLUEPRINT.md current
   - Document decisions and discoveries in real-time

### Optimal Parallel Workflows

```yaml
Scenario: Implementing a new feature
Parallel Execution:
  - Agent 1: Implement core functionality
  - Agent 2: Write tests for the functionality
  - Agent 3: Update documentation
  - Agent 4: Review for optimization opportunities

Scenario: Bug fixing
Parallel Execution:
  - Agent 1: Diagnose and fix the bug
  - Agent 2: Write regression tests
  - Agent 3: Check for similar issues elsewhere
  - Agent 4: Update error handling patterns

Scenario: Architecture planning
Parallel Execution:
  - Agent 1: Research best practices
  - Agent 2: Prototype solutions
  - Agent 3: Evaluate performance implications
  - Agent 4: Document architectural decisions
```
